# Ultimafia — Companion app for ultimafia.com

Ultimafia is a native SwiftUI client for [ultimafia.com](https://ultimafia.com), the online social-deduction game site. Browse the lobby, join or spectate games, chat and vote in real time, host your own setups, and keep up with direct messages, all from one app built for Apple platforms with no third-party dependencies.

**Platforms:** iPhone · iPad · native macOS

[![Join the TestFlight beta](https://img.shields.io/badge/TestFlight-Join%20the%20beta-0D96F6?logo=apple&logoColor=white)](https://testflight.apple.com/join/RjFMGD2E)

**Try the beta:** [Join the TestFlight beta](https://testflight.apple.com/join/RjFMGD2E). This requires Apple's [TestFlight](https://apps.apple.com/app/testflight/id899247664) app on your iPhone or iPad.

## Highlights

- **Lobby and games:** open, in-progress and finished games; join a seat or spectate; pregame ready checks.
- **Live game chat:** meetings, votes with a running tally, whispers and quotes, slash commands, emotes, role mentions with role art, and name autocomplete.
- **Hosting:** create games from setup search, with Mafia and Liars Dice game types.
- **Liars Dice:** a dice table with bids, Call Bluff and Spot On, and a per-round bet log.
- **Messages:** public site chat, DMs and multi-recipient conversations, with notifications.
- **Profiles:** player profiles, trophies, family, custom media and in-app settings.
- **Chat dictation:** on-device dictation with Ultimafia vocabulary (optional, off by default).
- **Live Activities:** pregame and ready-check status on the Lock Screen and Dynamic Island (iPhone).
- **iPad and Mac:** adaptive layouts for Split View and Slide Over, plus a native Mac app with a sidebar, toolbar, menus and keyboard shortcuts.
